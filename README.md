# PawConnect 🐾

## Project Overview

PawConnect is a Java Full Stack web application designed to provide a convenient platform for pet owners to access pet-related services. The application allows users to register, log in, manage appointments, explore pet products, and interact with different pet-related services.

The project was developed as part of my Java Full Stack internship.

- JavaScript

- MySQL

- Eclipse IDE
- Apache Tomcat

## Features

- User Registration
- User Login and Logout
- User Profile Management
- Pet Service Management
- Appointment Booking
- Appointment Management
- Pet Shop
- Product Management
- Database Integration

## Project Models

The application includes different models such as:

- User Model
- Pet Model
- Appointment Model
- Shop Model
- Product Model

## Project Workflow

1. User registers on the platform.
2. User logs into the application.
3. User can access pet-related services.
4. User can book and manage appointments.
5. User can browse products through the pet shop.
6. Application stores and retrieves information from the MySQL database.

## Database

MySQL is used to store application data such as:

- User details
- Pet details
- Appointment details
- Shop details
- Product details
